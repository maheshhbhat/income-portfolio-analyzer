# Maximum withdrawal Chrome UAT record

This is an owner-facing, repeatable Chrome acceptance path for Story #51. It
deliberately uses the **Illustrative comparison** data set; the maximum
withdrawal calculator must not use a provider snapshot or Refresh Data.

## Run procedure

1. Start the application with `npm start`, then open the displayed local URL in
   Google Chrome. Open DevTools and select the Console panel; enable Preserve
   log and clear existing messages.
2. Leave **Fund provider** set to **Illustrative comparison**. In **Maximum
   sustainable withdrawal**, enter `$10.00`, `10` years, and `2` percent
   inflation, then select **Calculate maximum withdrawal**.
3. Verify a visible dollar result and text saying it is the “highest verified
   first-year annual withdrawal” and that increasing it by `$0.01 fails`.
   Verify that the supporting allocation table has one or more rows, the
   projection has ten rows, and the disclosure says the result is illustrative,
   not financial advice, not a forecast, and not a certainty.
4. Replace the starting portfolio with `0` and calculate again. Verify the
   prior result, allocation, and projection are hidden; an actionable starting
   portfolio error is shown; and no withdrawal amount is displayed.
5. Inspect the Console. Record pass only when there are no errors generated by
   the page during either submission (ignore messages emitted by browser
   extensions, if any).
